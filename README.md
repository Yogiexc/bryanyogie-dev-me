## ⚡ High-Speed Aesthetics

Inspired by modern motorsports (like Lando Norris's aesthetics) and cutting-edge tech UI, this portfolio isn't just about reading text; it's about experiencing the code. It features:
- **GSAP ScrollTrigger:** Complex, smooth, and interactive scroll animations.
- **Custom Hardware Rendering:** WebGL & OGL integrations for a 3D Circular Gallery and Interactive 3D Lanyard/Card.
- **Micro-interactions:** Custom smart cursors, glitching text reveals, magnetic buttons, and image trails.
- **Fully Responsive:** Meticulously optimized for seamless viewing across ultra-wide desktops down to mobile devices.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/) & [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics:** [OGL](https://github.com/oframe/ogl) (for Circular Gallery) & Three.js
- **Smooth Scrolling:** [Lenis](https://lenis.studiofreight.com/)

## 📂 Key Features & Components

- **`Hero.tsx`**: A dynamic landing sequence with aurora backgrounds, glitch text typography, and a 3D tilt-responsive profile card.
- **`StickyScrollStory.tsx`**: A pinned scroll sequence utilizing a 240-frame image sequence rendered on an HTML5 `<canvas>` that scrubs based on the scroll position.
- **`CertificatesGallery.tsx`**: A continuous 3D cylindrical gallery utilizing OGL to display certificates in an endless looping carousel.
- **`HorizontalTimeline.tsx`**: A sideways-scrolling timeline detailing my journey from TKJ (Computer & Network Engineering) to Informatics Engineering.

## 🚀 Running Locally

Want to see the code in action?

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yogiexc/bryanyogie-dev-me.git
   cd bryanyogie-dev-me
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
